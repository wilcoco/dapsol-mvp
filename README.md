# 답설 MVP

**오늘 내가 찾고 만든 답이 다음 사람의 길이 됩니다.**

질문 → 사람의 답변·경험 → 직접 적용한 결과 → 다른 사람의 재사용.
답을 만든 사람, 설명을 보탠 사람, 그 가치를 알아본 사람의 기록이 이어지는 독립 MVP입니다.

## 구현한 첫 순환

- 공개 공간 / 나만 보기 / 초대로 참여하는 비공개 그룹
- Google·네이버·카카오 OAuth 연결 코드 + 별도 아이디·비밀번호 가입
- 독립적인 미해결 질문, 질문 없이 직접 경험 쓰기, 한 질문의 여러 답
- 작성자 신원, 적용 조건, 근거, 실제 관찰일과 기록일
- 개인 저장 / 질문자의 도움된 답 선택 / 적용 결과 / 보강·정정 / 재사용을 각각 기록
- 답변 수정은 새 버전. 과거 선택·투자는 당시 버전에 고정
- 복수 원천 버전, 출처에서 이어 묻기, 반영한 보강자의 이름 보존
- 원천 수정 시 직접·간접 파생 답의 재검토 표시. 과거 기록은 보존
- 단어 검색 + 명시적으로 클릭하는 Google 외부 검색 링크
- 선택적으로 연결하는 비공개 Anthropic 대화, 검토한 질문으로 사람에게 넘기기
- 본인 답의 자기 평가를 제외한 적용·재사용 인정 기록
- 작성자 선투자, 실험 포인트 예치/회수, 정수 원장과 중복 회수 방지

공개 지식 읽기는 무료입니다. 포인트는 현금 가치·배당·구매·송금이 없는 파일럿입니다.
신규 계정에 100P를 한 번 부여합니다. 후속 투자금을 기존 참여자에게 배당하지 않습니다.
출처 복제, 답 선택, 단순 투자만으로 검증됐다고 표시하지 않습니다.

## 실행

Python 3.13 기준, FastAPI + Jinja + SQLite. 별도 프런트엔드 빌드가 없습니다.

```sh
python -m venv .venv
# 가상환경 활성화 후
pip install -r requirements-dev.txt
# 환경변수를 설정하세요. .env.example은 예시이며 자동으로 로드하지 않습니다.
APP_ENV=development BASE_URL=http://127.0.0.1:8010 uvicorn app.main:create_app --factory --port 8010
pytest
```

PowerShell:

```powershell
$env:APP_ENV='development'
$env:BASE_URL='http://127.0.0.1:8010'
python -m uvicorn app.main:create_app --factory --port 8010
```

## 배포

Dockerfile과 railway.json을 포함합니다. Railway의 **새 프로젝트/서비스 + /data 영속 볼륨 + 단일 복제본**으로 운영합니다.
`DATABASE_PATH=/data/dapsol.db`, 안정적인 `SESSION_SECRET`, HTTPS `BASE_URL`이 필요합니다.
Railway에서 영속 볼륨 없이 시작하거나 DB가 볼륨 바깥을 가리키면 시작을 거부합니다.

[배포·로그인 설정](docs/deployment.md) · [제품 계약과 완료 기준](docs/product-contract.md) · [검증 기록](docs/verification.md)

## 첫 후속 통합

0.2.0에서는 dapsol의 사람 지식 검색과 Workwork Quick View의 관찰·재확인 원칙을 함께 적용합니다.
사용자가 접근 가능한 답변 버전을 직접 선택해 AI에게 참고하게 하고, 작성자·버전·근거·당시 확인 시각을 응답별로 보존합니다.
사람에게 질문을 넘길 때도 원천 버전이 따라갑니다. 원문 작성자의 재확인은 원래 관찰일을 바꾸지 않습니다.
[통합 출처와 후속 순서](docs/reuse-plan.md)

## 현재 범위

검색은 최근 500개 접근 가능한 질문에서 단어로 찾는 초기 구현이며 결과는 최대 50개입니다. 벡터 검색이 아닙니다.
독립 검증, 현상금 계약·분쟁 처리, 투자 배당, 사람 자동 매칭, 조직의 업무 배정·자동 보고는 후속 범위입니다.
게시물/계정 삭제·신고·계정 복구 도구, 다중 서버, 대용량 색인은 아직 없어 소규모 파일럿을 대상으로 합니다.
실제 OAuth/AI 사용에는 운영자의 제공자 설정이 필요합니다. 연결 전에는 해당 기능을 준비 중으로 표시합니다.
그룹의 외부 공개 전환과 외부 전문가의 질문 단위 초대는 제공하지 않습니다.
적용 결과는 사람당 답 버전당 한 건으로 보존되며, 결과의 별도 정정 버전은 후속 범위입니다.

기존 CAMS-KnowledgeNet, dapsol, QAQA, Workwork Quick View/Cloud의 설계 논의를 참고했습니다.
기존 서비스의 운영 데이터, 로그인 계정, 데이터베이스를 복사하거나 통합하지 않았습니다.
