## 브라우저

로컬 Chrome/Playwright에서 데스크톱 1440px와 모바일 390px 홈을 렌더링하고 스크린샷을 확인했다.
모바일 가로 넘침 없음.

Chrome의 분리된 세 사용자 세션에서 실제 폼으로 가입 → A 질문 → B 경험 답변 → A 선택·적용 → C 검색·재사용·파생 질문까지 통과했다.
데스크톱/모바일 질문 화면을 확인했고 JavaScript 페이지 오류는 없었다.
첫 브라우저 검증에서 `no-referrer`가 폼 POST의 Origin을 null로 만드는 문제를 발견해 `same-origin`으로 수정했다.
CSRF와 명시적인 외부 Origin 거부는 유지하며 수정 후 브라우저 시나리오를 다시 통과했다.
재현 스크립트: `tests/browser-smoke.cjs` (폐기 가능한 로컬 DB에서만 실행).

원격 코드 업로드는 GitHub 연결의 새 저장소 쓰기 권한 확인을 기다리는 중이다. Railway 프로젝트·도메인·환경변수를 준비했고 영속 볼륨 설정을 staging했다. 실제 배포 성공을 확인한 기록은 아직 없다.

## 아직 검증되지 않은 범위

실제 Google/네이버/카카오 제공자 왕복, 실제 외부 AI 호출, 큰 데이터의 검색 성능,
다중 서버 운영, 포인트 남용 대응, 백업 복구 훈련, 독립적 보안 감사.
사용자가 결과를 남겼다는 사실 자체는 사실 검증이나 보상의 자동 지급 근거가 아니다.
