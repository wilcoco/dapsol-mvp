# 기존 프로젝트 기능의 단계적 통합

첫 MVP는 `mvp-v0.1.0`으로 보존한다. 후속 작업은 `integrate-human-context`에서 진행한다.
기존 서비스의 DB·사용자 계정·운영 환경변수를 가져오지 않는다.

## 첫 통합: 사람이 남긴 답을 AI가 근거와 함께 참고하기

- 참조: dapsol `src/lib/chat/human-knowledge-retrieval.ts`, commit f4234c26fec622b401224e232f1570e73981506b.
- 재사용할 흐름: 사람 답·의견을 찾아 AI 문맥에 제공하고 원천을 추적.
- 보완할 점: 실제 작성자와 정확한 버전 연결, 읽기 권한 선확인, 출처를 사용자가 선택, 제공된 문맥과 실제 인용/성과를 구분.
- 원본의 작성자 누락 fallback, 투자자 수를 신뢰로 표현하는 방식, 콘솔 로그만 남기는 citation TODO는 계승하지 않는다.

## 함께 적용: 언제 관찰하고 다시 확인했는가

- 참조: workwork-quickview `server/briefing.mjs`의 evidenceFreshness, commit bd0a7e6462d5c0c02488a66774bc7d93cb70daae.
- 재사용할 원칙: 제출 시각 대신 실제 관찰·재확인 시각으로 경과를 설명.
- 다른 점: 일반 지식에 일괄 7일 만료를 부여하지 않는다. 최근 확인 날짜와 경과 일수를 보여 주고 실제 적용 조건을 함께 읽도록 한다.
- 확인 행위는 원문 작성일이나 원래 관찰일을 덮어쓰지 않는다. 재확인은 사실의 독립 검증으로 표시하지 않는다.

## 다음 통합 단위

1. Workwork Cloud: 실행 경험의 정정과 관찰 근거. 목표→질문→사람의 보고→판단→후속 결과를 그룹 기능으로 연결.
2. QAQA: 여러 답·보강·반론의 관계 탐색과 검색. 관계 종류가 사실 판정을 대신하지 않게 한다.
3. CAMS: 기여 평가와 현상금/예치 원장. 실제 노동 보상과 지식 투자 계약을 분리하고 총량 보존·분쟁 경로를 먼저 검증.
4. 벡터 검색: 현재 접근 정책을 공유하고 결과마다 원문 버전·작성자·정정 상태를 반환. 투자 잔액으로 사실 여부를 판정하지 않는다.

각 통합 단위마다 사용자 흐름과 권한 회귀 테스트가 통과한 뒤 main에 반영한다.
